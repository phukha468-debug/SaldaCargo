# 04. Стандарты UI, Плотности Данных и Языка

## 1. Фундаментальное правило UI: Dense 1-Line Layout

> Обязательно для всех активных платформ: **Web Dashboard (`apps/web`)**, **MAX MiniApp (`apps/miniapp`)** и ботов (Telegram / MAX).

1. **Приоритет одной строки (1-Row Priority):**
   - Ключевая информация по транзакциям, заявкам, рейсам, заказ-нарядам, начислениям и строкам таблиц размещается строго в **1 строчку**.
   - Эффективно утилизировать горизонтальное пространство справа: бейджи, статусы, теги, суммы и кнопки действий размещаются в ту же строку, а не переносятся отдельным блоком вниз.
2. **Лимит строк (максимум 2 строки):**
   - Перенос на 2-ю строчку допустим только на узких мобильных экранах, где физически не хватает ширины для 1 строки.
3. **Правило 3-й строки — категорический запрет раздувания:**
   - Запрещено создавать 3-ю строчку в элементах списков и таблиц.
   - Все вторичные детали, история, комментарии и расширенные формы убираются в **модальное окно (`Modal`)** или под **спойлер / аккордеон (`Accordion` / `Spoiler`)**.
4. **Паттерн списков вместо узких канбан-колонок:**
   - Для конвейеров и досок статусов использовать **карточки-папки** переключения стадий + **полноширинный однострочный список** внутри выбранной папки.

## 2. Языковые конвенции

| Контекст                                                        | Язык / Стиль                                                          |
| --------------------------------------------------------------- | --------------------------------------------------------------------- |
| Интерфейс (кнопки, заголовки, статусы, ошибки для пользователя) | **Русский**                                                           |
| Ответы AI-ассистента и документация бизнес-логики               | **Русский**                                                           |
| Коммит-сообщения                                                | **Русский** (с префиксом типа: `feat(scope): ...`, `fix(scope): ...`) |
| Код, имена переменных, функций, типов, комментарии в коде       | **Английский**                                                        |
| Таблицы БД, колонки, миграции                                   | **Английский, `snake_case`**                                          |
